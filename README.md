# G6 Template Tree Editor

基于 [AntV G6 4.x](https://g6-v4.antv.vision/) 的树图TreeGraph实现，用于在一个结构已知的树图模板中动态增删内容节点。

适用于结构模板固定、但需要内容更新的场景，例如 BOM（物料清单）等。
